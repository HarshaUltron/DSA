# Step 1: Binary Search Intuition

Imagine a dictionary.

Can you search a word by checking every page?

Yes.

Time:

```text
O(n)
```

Instead, you open the middle.

If your word is:

```text
APPLE
```

and middle word is:

```text
MANGO
```

You know:

```text
APPLE < MANGO
```

So throw away the entire right half.

Repeat.

This is Binary Search.

Every iteration removes **half** the search space.

Time:

```text
O(log n)
```

---

# Binary Search works only when

The search space is **sorted** or **monotonic**.

Example:

```python
[1,3,5,8,10,12]
```

Not:

```python
[8,2,10,4]
```

---

# Template 1 (Most Important)

```python
left = 0
right = len(nums)-1

while left <= right:

    mid = left + (right-left)//2

    if nums[mid] == target:
        return mid

    elif nums[mid] < target:
        left = mid + 1

    else:
        right = mid - 1

return -1
```

Memorize this.

---

# Why

```python
mid = left + (right-left)//2
```

instead of

```python
(left+right)//2
```

Because in Java/C++:

```text
left+right
```

can overflow.

Python doesn't overflow here, but interviewers still prefer the safer form.
